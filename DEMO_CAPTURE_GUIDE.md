# Capturing the prototype for a slide

The site is ready to capture at presentation size. No separate mock-up is needed: open `index.html` in a browser and capture the live page.

## Suggested screenshots

1. **Museum landing page:** show the hero and the start of the Moon/Mars exhibit section.
2. **Exhibit detail:** open Apollo 11 or Ingenuity so the mission timeline and NASA source link are visible.
3. **Mini-game:** open Land the Eagle or Repair the Rover and show an in-progress prompt.

For a clean 16:9 capture, maximize the browser, set zoom to 90–100%, and use the operating system’s screen capture tool. On a narrow screen, capture a separate portrait view to show the responsive layout.
